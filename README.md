**Additions for the journal version, beyond the "must do" list in section 4:**
- A matched-duration experiment to separate sample count from signal content (R2-1).
- A causal, on-device segmentation baseline so the paper isn't only a negative result (R1).
- An amplitude baseline whose direction is chosen on the calibration participants, with bootstrap CIs (R2-3).
- Full calibration and bootstrap pseudocode, the sampling frequency and checkpoint IDs, plus public code (R2-2).
- A conventional structure: Introduction, Related Work, Methodology with the research questions, Results, Discussion and Limitations (R2).
- A second public dataset if at all possible. Ten participants from one lab is the generalisation weakness journal reviewers will push hardest on.

Candidate venues: IEEE Internet of Things Journal, IEEE Sensors Journal, ACM IMWUT, ACM Transactions on Computing for Healthcare, and Pattern Recognition Letters (short methodological papers). Check each journal's scope and its policy on papers previously submitted to conferences.
